# Assets for the ARMI docs

A place to store raw assets for graphs and charts in the [ARMI repo](https://github.com/terrapower/armi).

In the course of building docs for a large project like ARMI, many diagrams and charts may have to be generated. Maybe these will be simple Graphviz, or complicated PowerPoint files. But if people need to update those plots and diagrams, they will want the original raw file to work from.

The repo is just a helper repo for [ARMI](https://github.com/terrapower/armi), to collect such raw asset files, so they are not lost.


## Organization

As much as possible, we will try to match the location of the asset files here with their used location in ARMI.
